# REST API проєкту Online Library

Базова адреса: `http://localhost:3000/api`

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
|---|---|---|---|---|---|
| 1 | `/categories` | GET | перелік категорій книг | 200 | 500 |
| 2 | `/categories/:id` | GET | одна категорія | 200 | 404 |
| 3 | `/categories/:id/books` | GET | книги категорії | 200 | 404 |
| 4 | `/books` | GET | перелік із фільтрацією | 200 | 400 |
| 5 | `/books/:id` | GET | картка книги | 200 | 404 |
| 6 | `/books` | POST | створення книги | 201 | 422 |
| 7 | `/books/:id` | PUT | повне оновлення | 200 | 404, 422 |
| 8 | `/books/:id` | DELETE | видалення | 204 | 404 |
| 9 | `/loans` | POST | оформлення видачі книги | 201 | 422 |

## Параметри GET /books
| Параметр | Тип | Приклад | Опис |
|---|---|---|---|
| `category` | int | `?category=3` | фільтр за категорією |
| `author` | string | `?author=Шевченко` | фільтр за автором |
| `q` | string | `?q=Кобзар` | пошук за назвою книги |
| `sort` | enum | `?sort=year_desc` | сортування |
| `page` | int | `?page=2` | номер сторінки |
