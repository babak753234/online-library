# Вимоги до проєкту Online Library

## 1. Призначення
Веб-застосунок для перегляду каталогу книг, пошуку за авторами та читачами, фільтрації видань і оформлення видачі книг.

## 2. Ролі користувачів
- Читач — перегляд каталогу, пошук, фільтрація, оформлення видачі.
- Бібліотекар — додавання, редагування, видалення книг, авторів, читачів і записів видачі.

## 3. Сутності предметної області
| Сутність | Атрибути |
| -------- | ---------------------------------------------------------- |
| Author   | id, full_name, country, birth_year                         |
| Book     | id, author_id, title, isbn, year, available_copies         |
| Reader   | id, full_name, email, phone, card_number                   |
| Loan     | id, book_id, reader_id, loaned_at, due_date, status        |

## 4. Зв’язки
Author 1 – ∞ Book; Book 1 – ∞ Loan; Reader 1 – ∞ Loan

## 5. Сторінки
1. `/`               головна: банер, новинки та популярні видання
2. `/catalog`        каталог: пошук і фільтр за автором та наявністю
3. `/book/:id`       картка книги та історія видач
4. `/loan`           форма оформлення видачі з валідацією
5. `/contact`        контакти бібліотеки та зворотний зв’язок

## 6. Функціональні вимоги
F1. Дані завантажуються асинхронно з сервера.
F2. Фільтрація не перезавантажує сторінку.
F3. Форма перевіряє ім’я, телефон та e-mail.

## 7. Нефункціональні вимоги
N1. Адаптивність від 360 px.
N2. Lighthouse Performance ≥ 85.
